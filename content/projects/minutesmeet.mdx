## Overview

MinutesMeet is an AI-powered meeting-minutes generation system designed to convert recorded meeting audio into structured meeting documentation.

The system is designed around a two-stage machine-learning pipeline that combines automatic speech recognition with large language model processing.

The first stage uses OpenAI's Whisper model to convert recorded meeting audio into raw transcript text.

The second stage uses Meta's Llama-3.2-3B-Instruct model to analyze the transcript and generate structured meeting minutes containing information such as attendees, discussion points, key decisions, takeaways, and action items.

> **Project status:** MinutesMeet's core machine-learning pipeline is implemented around Whisper transcription and Llama-based meeting-minute generation, with the architecture designed for interactive frontend integration and real-time output streaming.
