## Overview

AEGIS is an AI security system designed around automated red-teaming of language models.

The system treats AI security testing as a pipeline rather than a single prompt-generation task.

An attack knowledge base provides known attack patterns. An LLM-based red-team agent generates and mutates attack variants. A DSA layer removes duplicates and prioritizes the testing queue. The target model is evaluated in a controlled environment. Machine-learning components classify attacks and estimate severity. The resulting vulnerability information can then be preserved through a blockchain-backed audit layer.

The core workflow is:

```text
Attack Knowledge Base
        ↓
LLM Red-Team Agent
        ↓
DSA Deduplication + Scheduling
        ↓
Target AI Model
        ↓
ML Classification / Severity
        ↓
Vulnerability Record
        ↓
Blockchain + IPFS Audit Layer
