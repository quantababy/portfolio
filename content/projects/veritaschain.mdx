## Overview

VeritasChain is a decentralized AI fact-checking system designed around a simple engineering problem:

**How can an AI-generated fact-checking result be supported by retrieved evidence, evaluated using source relationships, and preserved as an auditable record?**

Instead of treating fact checking as a single LLM request, VeritasChain separates the workflow into multiple processing layers.

A claim moves through DSA-based processing, verification orchestration, evidence retrieval, LLM-based verdict generation, source-trust analysis, and blockchain-backed persistence.

Each layer has a defined responsibility rather than relying on one model to perform the entire verification process.

The DSA layer handles claim processing and prioritization. The verification layer coordinates the fact-checking workflow. The RAG layer retrieves relevant evidence. The graph-based ML layer works with source relationships and trust information. The blockchain and IPFS layer provides a persistent audit trail for the resulting record.

> **Project status:** Completed end-to-end implementation combining DSA, LLM/RAG, graph-based machine learning, real-time backend communication, and blockchain-backed verification.

## System workflow

The complete VeritasChain workflow is:

![VeritasChain system workflow showing the DSA engine, AI agent, LLM and RAG pipeline, GNN source-trust engine, and blockchain audit layer](/projects/veritaschain/workflow.png)

The system separates verification into independent processing stages.

A claim enters through the frontend and is sent to the FastAPI backend. The processing layer handles claim organization before the verification workflow retrieves supporting evidence and generates a structured result.

The source-trust layer adds graph-based information to the verification process. The resulting record can then be connected to the blockchain and IPFS persistence layer for auditability.

The processing flow is:

```text
User Claim
    ↓
DSA Processing Engine
    ↓
Verification Agent
    ↓
Evidence Retrieval
    ↓
LLM + RAG
    ↓
GNN Source-Trust Scoring
    ↓
Structured Verdict
    ↓
Blockchain + IPFS Audit Record
