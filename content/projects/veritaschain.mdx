## Overview

VeritasChain is a decentralized AI fact-checking system designed to answer a difficult question:

**How can an AI-generated fact-checking result be supported by evidence, evaluated for source credibility, and preserved as an auditable record?**

Instead of treating fact checking as a single LLM request, VeritasChain separates the process into multiple engineering layers.

A claim moves through a DSA processing engine, an autonomous verification agent, retrieval-augmented generation, source-trust scoring, and finally a blockchain-backed audit layer.

The architecture gives each stage a specific responsibility rather than relying on one model to perform the entire verification process.

The DSA layer handles claim processing and prioritization. The AI agent coordinates verification operations. The RAG layer retrieves supporting evidence. The graph-based ML layer evaluates source relationships and trust. The blockchain layer provides an auditable record of the resulting verdict.

> **Project status:** VeritasChain is a completed project combining DSA, LLM/RAG, graph-based machine learning, real-time backend communication, and blockchain-backed verification.

## System workflow

The complete VeritasChain workflow is:

![VeritasChain system workflow showing the DSA engine, AI agent, LLM and RAG pipeline, GNN source-trust engine, and blockchain audit layer](/projects/veritaschain/workflow.png)

The system separates the verification process into independent processing stages.

A claim first enters the application through the frontend. The backend then processes and prioritizes the claim before passing it through the autonomous verification and evidence-retrieval layers.

The verification result is evaluated using source relationships and trust information before the final verdict is preserved through the blockchain and IPFS layer.

    ↓

    ↓

    ↓

    ↓

    ↓
Blockchain + IPFS Audit Record
