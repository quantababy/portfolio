## Overview

VeritasChain is a decentralized AI fact-checking system designed to answer a difficult question:

**How can an AI-generated fact-checking result be supported by evidence, evaluated for source credibility, and preserved as an auditable record?**

Instead of treating fact checking as a single LLM request, VeritasChain separates the process into multiple engineering layers.

A claim moves through a DSA processing engine, an autonomous verification agent, retrieval-augmented generation, source-trust scoring, and finally a blockchain-backed audit layer.

The architecture gives each stage a specific responsibility rather than relying on one model to perform the entire verification process.

> **Project status:** VeritasChain is the completed first project in this portfolio. The implementation, testing, and measured results documented on this page will be based on the final working system.

## Architecture

The system is organized into several layers, with each layer responsible for a specific part of the verification pipeline.

### DSA processing engine

The DSA layer provides the processing backbone of the system.

The architecture uses data structures and algorithms for claim processing, including:

- Trie-based claim deduplication
- Priority-queue based scheduling
- Graph-based source relationships
- Network analysis for source relationships

This layer organizes and processes claims before they reach the more computationally expensive AI and retrieval stages.

### AI agent

The AI agent coordinates the verification workflow.

The system uses a LangGraph-based agent to coordinate specialized operations rather than relying on a single model response.

The agent can orchestrate operations such as:

- Web search
- Evidence retrieval
- Source reputation scoring
- Blockchain lookups
- Article scraping
- LLM-based fact checking

The agent coordinates these operations to produce the information required for a structured verification verdict.

### LLM + RAG

The retrieval layer combines large language models with retrieval-augmented generation.

FAISS provides the vector-search component, while LangChain coordinates the retrieval pipeline.

The purpose of this layer is to ground the verification process in retrieved evidence instead of relying entirely on the language model's internal knowledge.
